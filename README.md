# Datacenter i Sverige

Publik kartprototyp och analysunderlag för att utforska datacenteranläggningar och datacentermarknader i Sverige.

## Öppna kartan

- [Projektets startsida](https://gislab-se.github.io/datacenter/)
- [Interaktiv karta över datacenter i Sverige](https://gislab-se.github.io/datacenter/outputs/maps/datacentermap_sweden_interactive_map.html)

## Innehåll

- `scripts/extract_osm_datacenters_sweden.py` hämtar och bearbetar anläggningsdata.
- `scripts/make_datacentermap_sweden_map.py` bygger den publicerade kartan.
- `outputs/datacentermap_sweden/` innehåller tabeller över anläggningar och marknader.
- `outputs/datacentermap_sweden_enriched/` innehåller geografiskt berikade resultat per kommun och län.
- `outputs/maps/` innehåller publicerade kartprodukter.

## Status och användning

Materialet är ett utforskande analys- och visualiseringsunderlag. Kontrollera källor, aktualitet och metod innan resultat används som beslutsunderlag. Repo:t publiceras med GitHub Pages.
